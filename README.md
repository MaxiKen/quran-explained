# quran-explained

Quran explained verse by verse.

See [UX_UPDATES.md](UX_UPDATES.md) for the v2.3 reading-continuity, on-screen navigation, read-aloud player dock and tafsir-sheet updates — plus the v2.2 commentary eBook, themes and accessibility work.

## Structure

- `index.html` — app shell: header navigation cluster, tafsir sheet, read-aloud dock and player orb live here.
- `js/chapters-meta.js` → `js/reading-memory.js` → `js/router.js` → `js/read-aloud.js` → `js/app.js` — load order is significant; the three middle modules must stay before `app.js`.
- `js/reading-memory.js` — remembers where you stopped per screen (anchors, not pixels) in `localStorage`.
- `js/router.js` — in-app history, back/forward stack, back-button guard, edge-swipe gestures.
- `js/read-aloud.js` — the bottom read-aloud dock (speech, lyrics follow, navigator, sleep timer) and the shared floating player orb.
- `css/styles.css` — the whole design system; v2.3 layers are appended at the end.
- `data/chapter_NNN.js` + `data/tafsir_NNN.json` — per-chapter content, generated by `scripts/`.
- `scripts/editorial_pass.py` — editorial pass over `markdown commentry/` that trims each verse section to its substance (see [EDITORIAL_PASS.md](EDITORIAL_PASS.md)); `scripts/build_tafsir_json.py` then rebuilds `data/tafsir_NNN.json` from the markdown.

Serve the folder statically (`python3 -m http.server`) — the service worker and the `data/` fetches need an origin, not `file://`.
